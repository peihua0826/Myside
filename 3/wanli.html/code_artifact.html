品嚐人氣爆棚的金山鴨肉與美味古早味小吃，穿梭在紅磚拱廊下感受百年老街的熱鬧與人情味。

🏛️ 總督溫泉

舊金山總督溫泉歷史風華

📍 金山區．百年溫泉建築
